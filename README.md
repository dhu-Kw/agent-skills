# agent-skills
## Fill Travel Reimbursement
1. 准备与读取
用户连接内网／VPN、登录并打开目标报销单。Skill 收集 PDF 与发票号对应关系，提取所有页面的行程。
2. 合并与校验
按上车日期、时间升序排列，保留来源文件和原行程序号。核对行程数量、逐笔金额合计、行程单总额及指定发票可用情况。缺失数据、金额差异、发票不存在或余额不足时，报告并询问。
3. 展示清单并确认
展示实际待填字段、关联发票号、来源、各文件小计及总计。疑似重复记录标记出来，未经确认不删除。用户确认后才修改网页。
4. 处理页面已有内容
发现已有行程时，询问是否清空：
- 同意：仅清空“日常交通费”中的行程，逐行点击左侧“×”。
- 不同意：保留已有内容，优先使用空白行，不覆盖已有行。
空白行不足时，通过“+5”“+10”补足。
5. 逐项填写与核对
每笔行程占一行，多行可关联同一张发票。关联后核对单程金额，防止页面自动带入发票总额。填写中出错立即停止，保留已完成部分，报告出错行和待完成项；恢复时先检查现场，避免重复填写。
6. 交给用户审核
核对已填日期、地址、金额、发票及行数，报告完成情况，提醒用户调整费用归属。不点击保存、提交或下一步
